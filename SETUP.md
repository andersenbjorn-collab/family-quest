# Family Quest - Oppsettsinstruksjoner

## Krav
- Node.js 18 eller nyere: https://nodejs.org/en/download

## Start appen

1. Åpne Terminal / PowerShell
2. Naviger til prosjektmappen:
   ```
   cd "C:\Users\Bjørn\Documents\family-quest"
   ```
3. Installer avhengigheter:
   ```
   npm install
   ```
4. Start utviklingsserveren:
   ```
   npm run dev
   ```
5. Åpne nettleseren og gå til: http://localhost:3000

## Bygg for produksjon
```
npm run build
npm start
```
